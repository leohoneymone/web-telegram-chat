# Web Telegram Chat

## О клиенте

Веб-приложение для обмена сообщениями с мессенджером Telegram на основе [Green-API: Telegram](https://green-api.com/telegram). Реализует основные функции мессенджера, работая с текстовыми сообщениями.

Клиент находится на этапе минимаьного жизнеспособного продукта (MVP).

Ссылка: https://leohoneymone.github.io/web-telegram-chat/

## Инструкция по развёртыванию

Для сборки и работы с приложением необходимо использовать следующие зависимости:

- `node` 22.21 и выше
- `npm` 10.9 и выше

Дальнейшие шаги для локального развёртывания системы:

```sh
# Клонировать репозиторий (или загрузить его в формате .zip архива)
git clone https://github.com/leohoneymone/react-game-store.git

# Установить зависимости
npm ci

# Запуск с помощью Vite Dev Server
npm run dev

# Сборка проекта для дальнейшего развертывания
npm run prod
```

Для развёртывания собранного проекта используйте веб-сервер, например `apache2` или `nginx`. Развёртывание системы может производится на конфигурации по умолчанию - дополнительных настроек не требуется.

## Технологический стек:

- Основные зависимости: `React`, `TypeScript`
- Компоненты: `Ant Design`,
- Стили: `SCSS`, `SCSS Modules`,
- Управление состояниями: `Zutand`, `Zustand immer middleware`,
- Запросы на сервер: `axios`, `TanStack Query (React Query)`,
- Качество кода: `ESlint`, `Prettier`,
- Сборка: `Vite`
